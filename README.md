# BioTrack LIMS - System Information & Bioprocess Tracker

Un système d'information de laboratoire (LIMS) léger développé en JavaScript Vanilla pour la traçabilité des lots biopharmaceutiques.

## Fonctionnalités
- **Contrôle Qualité Automatisé :** Vérification en temps réel des tolérances de culture (pH, température).
- **Séquençage ADN/ARNm :** Outil de transcription rapide de séquences nucléotidiques.
- **Gestion des lots :** Filtrage par statut de conformité et recherche dynamique.
- **Persistance :** Sauvegarde des données via LocalStorage.
